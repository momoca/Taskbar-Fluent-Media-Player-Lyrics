# Taskbar Fluent Media Player Lyrics

[English](README.md) · [简体中文](README_CN.md) · **Русский**

Мод для [Windhawk](https://windhawk.net/), размещающий медиаплеер в стиле Fluent, синхронизированный текст песни и аудиовизуализатор прямо на панели задач Windows 11. Этот форк расширяет [Salyts/Taskbar-Fluent-Media-Player](https://github.com/Salyts/Taskbar-Fluent-Media-Player): добавлены подсветка по реальным временным меткам слов и полноценный плеер на панели задач каждого монитора.

Текущая версия исходника: **`2.0`**. См. также [полный список возможностей на английском](Features-and-Player-Support.md) и [технические заметки на китайском](LYRICS.md).

lyrics7: Если встроенный SMTC NetEase не передаёт позицию, текст синхронизируется с проверенными часами клиента, доступными только для чтения. Проверено с NetEase 3.1.41.205564 x64. При недоступной позиции текст скрывается; другие версии могут потребовать адаптации. См. [технические заметки](LYRICS.md).

## 1. Возможности

| Раздел | Что реализовано |
|---|---|
| Плеер на панели задач | Обложка, название, исполнитель, воспроизведение/пауза, предыдущий/следующий трек, перемотка на ±5 секунд, случайный порядок, повтор и переключение медиасессий. Доступность команд зависит от выбранного приложения. |
| Оформление Fluent | Acrylic, Mica/Mica Alt, размытие обложки, сплошной цвет, градиенты, цвета светлой/тёмной темы, настройка шрифтов, значков, скруглений, отступов и положения. |
| Полный плеер на нескольких мониторах | Отдельный плеер с полным оформлением на каждой доступной панели задач: обложка, текст, кнопки, визуализатор и область текста песни при наличии текста. Состояние воспроизведения и настройки общие. |
| Отдельная область текста песни | Текущая и следующая строки рядом с исходными названием и исполнителем; компактный интервал и вертикальное центрирование. |
| Условное отображение | Область видна **только при включённой настройке и после получения текста текущего трека**. Во время поиска, при отсутствии текста или медиасессии и при выключенной настройке вся область скрывается, освобождая место. |
| Стабильный размер области | Ширина по умолчанию — **260 DIP**, диапазон — **80–1200 DIP**. Высота и размер шрифта подстраиваются под высоту панели задач и DPI монитора. После получения текста смена строк, вступление и пустые строки не меняют размер области. |
| Длинные строки | Текущая строка прокручивается в заданных границах. При наличии временных меток слов прокрутка следует за исполнением; обычный LRC прокручивается туда и обратно. Длинная следующая строка сокращается многоточием. |
| Подсветка по реальному времени слов | Используются метки QQ QRC, NetEase YRC и локального enhanced LRC. Обычный LRC синхронизируется только по строкам: **время слов не оценивается и не распределяется равномерно**. Подсветку можно отключить отдельно. |
| Источники текста | Сначала локальные файлы, затем QQ Music, NetEase и LRCLIB с резервными попытками. Плеер и источник текста не обязаны быть одним сервисом. |
| Синхронизация | Обработка паузы и перемотки, экстраполяция с учётом скорости воспроизведения, глобальный и отдельные для источников сдвиги **±10 000 мс**, сглаживание целосекундной шкалы Apple Music. Положительный сдвиг показывает текст раньше, отрицательный — позже. |
| Выбор источника | Отдельные переключатели, настраиваемый приоритет, ручное переключение с пропуском отключённых источников и периодическая проверка выбора. Воспроизводящие сессии имеют преимущество; браузеры по умолчанию последние. |
| Поиск и получение | Идентификаторы треков сервисов, сопоставление нескольких исполнителей, проверка смены трека, кэш в памяти на **64** успешных результата и повтор через **30 секунд** после неудачи. |
| Существующие функции | Настраиваемые действия мыши, контекстное меню, всплывающий мини-плеер, прокрутка названия/исполнителя и скрытие при отсутствии медиа, полноэкранном режиме или бездействии. |
| Аудиовизуализатор | WASAPI loopback + FFT, пять форм, пять цветовых режимов, шесть пресетов EQ, настройка размера, положения и чувствительности. |

## 2. Настройка нескольких мониторов

Включите панели задач Windows на нужных дисплеях, затем настройте следующие параметры в **Main Settings**:

| Параметр | Поведение |
|---|---|
| Show identical full player on all monitors (`mirrorAllMonitors`) | Включён по умолчанию. Создаёт полный плеер на каждой обнаруженной панели задач, а не только копию текста песни. |
| Monitor (`monitor`) | Выбирает основной экземпляр. Если многомониторное отображение выключено, выбирает дисплей единственного плеера. Нумерация может отличаться от параметров экрана Windows. |
| Secondary taskbar missing anchor fallback (`mirrorMissingAnchor`) | Если выбранная кнопка виджетов или другая опорная кнопка отсутствует, используется положение возле «Пуска» с резервированием места либо наложение у левого края без резервирования. Явно выбранные краевые положения сохраняют своё поведение. |
| Secondary player horizontal offset (`mirrorSecondaryOffsetX`) | Сдвигает только вторичные экземпляры: положительное значение — вправо, отрицательное — влево. |

Вторичные панели задач обнаруживаются периодически. У каждого экземпляра свой интерфейс и жизненный цикл отрисовки, но общие медиасостояние и настройки. Область текста учитывает высоту и DPI своей панели задач. **Mirror layout** меняет порядок элементов слева направо; это отдельная функция, не многомониторное отображение.

## 3. Установка и обновление

Требуются **Windows 11**, Windhawk и стандартная реализация панели задач, на которую рассчитан мод. Windows 10, сторонние замены панели задач и все сборки Windows не проверялись.

1. Установите [Windhawk](https://windhawk.net/).
2. Откройте [`taskbar-fluent-media-player.wh.cpp`](taskbar-fluent-media-player.wh.cpp) в этом репозитории и скопируйте **полный исходник из Raw**.
3. Создайте локальный мод в Windhawk, замените содержимое редактора этим исходником, сохраните/скомпилируйте и включите его. Для обновления существующей локальной копии замените её исходник и скомпилируйте заново.
4. Оставьте включённой только одну версию этого плеера. Отключите исходную версию из каталога или другую локальную копию, чтобы избежать дублирующих перехватов панели задач.
5. В настройках выберите положение и мониторы, затем запустите музыку. Включите **Show separate lyrics area** и получение текста из сети либо укажите папку локальных файлов.

Версия 2.0 использует отдельный ID Windhawk `taskbar-fluent-media-player-lyrics`. Если у вас была более ранняя локальная сборка, перенесите её настройки и отключите её перед включением версии 2.0.

## 4. Настройки текста и источников

### Main Settings → Text Area

| Настройка | Назначение |
|---|---|
| Show separate lyrics area | Главный переключатель; также требуется полученный текст текущего трека. |
| Lyrics area width | По умолчанию **260 DIP**, диапазон **80–1200 DIP**. При масштабе Windows 150% значение 260 DIP соответствует примерно 390 физическим пикселям. Высота регулируется автоматически. |
| Highlight real word timing | Подсветка по реальным меткам; при отключении сохраняется построчная синхронизация. |
| Fetch lyrics from QQ Music, Netease and LRCLIB | Включает или отключает получение из сети. |
| Local UTF-8 LRC folder | Также поддерживает текстовые QRC и YRC. Проверяется только указанная папка, без рекурсивного обхода. |
| Lyrics offset | Глобальная поправка синхронизации, суммируется со сдвигом выбранного источника. |

Имена локальных файлов: `Artist - Title.lrc`, `Title - Artist.lrc` или `Title.lrc`; те же правила для `.qrc` и `.yrc`. Недопустимые в именах Windows символы заменяются подчёркиваниями. Enhanced LRC требует реальных встроенных меток, например: `[00:01.00]<00:01.00>Hello <00:01.40>world<00:02.00>`. Для последнего фрагмента без конечной метки длительность не придумывается.

### Main Settings → Media Sources

У каждого источника свой переключатель и временной сдвиг. Автоматический выбор сначала учитывает воспроизведение, затем приоритет; ручной выбор сохраняется. Приоритет по умолчанию, от высокого к низкому:

```text
qq,netease,kugou,spotify,apple,soda,foobar,other,browser
```

Порядок получения: **сначала локальные файлы**; для NetEase — **NetEase → QQ Music → LRCLIB**; для остальных — **QQ Music → NetEase → LRCLIB**. Реальные метки слов используются при наличии; построчный текст остаётся построчным. Если все попытки неудачны, вся область текста скрывается.

## 5. Совместимость с плеерами

Мод получает метаданные и прогресс через **Windows SMTC**. Распознавание имени приложения не создаёт шкалу времени, которую приложение не публикует.

| Плеер | Интеграция и условия | Проверка |
|---|---|---|
| QQ Music | Отдельные настройки, QRC/LRC и числовые ID треков. | Клиент Windows и получение текста проверены. |
| NetEase Cloud Music | Отдельные настройки, прямое получение по `NCM-<числовой ID>`, YRC/LRC. При неполной шкале времени может потребоваться [inflink-rs](https://github.com/apoint123/inflink-rs); учитывайте поддерживаемые им версии клиента. | Поиск и получение по ID проверены; это не сквозная проверка каждой версии клиента. |
| KuGou / MoeKoeMusic | Отдельные настройки и текст от других сервисов. Неполная шкала родного KuGou может мешать синхронизации. [MoeKoeMusic](https://github.com/MoeKoeMusic/MoeKoeMusic) относится к этому источнику. | Версии клиентов в этом раунде не проверялись. |
| Spotify | Отдельные настройки, SMTC и текст от других сервисов. Доступа к аккаунту Spotify нет. | Распознавание проверено офлайн; клиент не проверялся. |
| Apple Music / iTunes | Отдельные настройки, сглаживание целосекундной шкалы и текст от других сервисов. Нужен клиент или конфигурация с SMTC. | Логика времени проверена офлайн; клиенты не проверялись. |
| Soda Music / Qishui Music | Распознаются SodaMusic, `com.soda.music` и китайские идентификаторы. Нужны корректные данные SMTC. | Распознавание проверено офлайн; клиент не проверялся. |
| foobar2000 | Нужен компонент вроде [foo_mediacontrol](https://github.com/ungive/foo_mediacontrol), публикующий трек и прогресс. | Распознавание проверено офлайн; клиент не проверялся. |
| Браузеры | Edge, Chrome, Firefox и другие распознаваемые браузеры. Сайт должен передавать название песни, исполнителя и прогресс; обычное название видео может не совпасть с песней. | Чтение медиасессий Edge проверено. |
| Другие SMTC-плееры | Общие настройки источника; нужны пригодные метаданные и шкала времени. | Совместимость со всеми приложениями не гарантируется. |

Сторонние плагины **не устанавливаются автоматически**. Наличие текста и реальных меток слов зависит от трека и сервиса, а не только от названия плеера.

## 6. Ограничения и устранение проблем

- **Область текста не видна:** проверьте главный переключатель, включение источника, метаданные, сетевое получение/локальные файлы и доступность сервиса. Скрытие во время поиска и после неудачи предусмотрено.
- **Текст не движется:** проверьте публикацию шкалы времени; при необходимости настройте дополнительный плагин. Временной сдвиг не исправляет отсутствующую шкалу.
- **Неверный текст или сдвиг:** проверяются название, набор исполнителей и доступная длительность, но нельзя гарантировать совпадение каждой записи. Попробуйте локальный файл; постоянную разницу исправляйте глобальным сдвигом или сдвигом источника.
- **Нет плеера на другом мониторе:** включите там панель задач Windows, многомониторное отображение, проверьте резервное положение и горизонтальный сдвиг.
- **Дублирование или наложение:** отключите другие копии мода и проверьте положение, ширину и резервные варианты.

Не реализованы: собственный источник текста KuGou, KRC, текст внутри аудиофайлов, переключатель перевода, дисковый кэш, сохранение сдвига для отдельных треков и анимации смены строк. **Поддержка плеера KuGou и источник текста KuGou — разные возможности.**

## 7. Сеть и конфиденциальность

При сетевом поиске метаданные трека или доступные ID отправляются QQ Music, NetEase и/или LRCLIB. Аккаунты плееров и пользовательские cookie входа не читаются. Для работы только с локальными файлами выключите сетевое получение. Успешные результаты кэшируются в памяти, не на диске; при выгрузке мода кэш теряется.

## 8. Исходники и проверка

- [`taskbar-fluent-media-player.wh.cpp`](taskbar-fluent-media-player.wh.cpp): самодостаточный исходник Windhawk, включая QRC и распаковку DEFLATE с ограничением размера. Для работы мода не нужны внешние Node.js или .NET.
- [Список возможностей на английском](Features-and-Player-Support.md), [на китайском](功能列表与播放器支持.md) и [технические заметки](LYRICS.md).
- [`tests/lyrics-parser-tests.ps1`](tests/lyrics-parser-tests.ps1): извлекает рабочую реализацию и проверяет форматы, криптографию, реальные метки слов, источники, приоритет и шкалу Apple. Запускается в Windows при наличии компилятора из комплекта Windhawk:

```powershell
powershell -ExecutionPolicy Bypass -File .\tests\lyrics-parser-tests.ps1
```

Текущая реализация прошла проверку исходника/настроек, компиляцию и офлайн-тесты. В тесте QQ получены 48 строк и 309 реальных временных фрагментов; поиск NetEase вернул 98 строк и 579 фрагментов, прямое получение по ID также успешно. Это не доказывает работу всех версий плееров. Скрипты установки для машины разработчика и сгенерированные бинарные файлы в обновление репозитория не входят.
